# Practice prototype rules — v1 historical reference

The isolated validation environment produced some saved v1 attempts during development. Their JSON/evidence/outcomes stay intact. V1 used three player decisions, the same original colour/full source history, skill-6 practical replies and independent skill-20 250,000/750,000-node checks. It required an absolute centipawn-score difference of at most 75 at each best/played pair and rejected a restricted score more than 30 above the unrestricted score. This was overly restrictive in winning positions: absolute evaluations can grow with deeper searches even when relative loss/objective remain supported. Repeating cached budgets also prevented useful recovery. Its material-draw path inherited the locked library's incorrect K+NN versus K adjudication.

[V2](mistake-practice.md) uses objective agreement and stable relative loss, admits supported stronger alternatives, adds distinct bounded deeper retry budgets and guards standard dead-material cases. Finished v1 attempts are read-only historical results. Pending v1 work ends ungraded without engine work; active attempts can be ended, and the exact original mistake can start a distinct v2 session. Old jobs cannot silently receive a new rule. This is development/validation history, not an earlier public release.
